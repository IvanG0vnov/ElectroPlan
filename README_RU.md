# ЭлектроПлан

Русскоязычное офлайн-приложение для рисования электрического плана дома и расчёта длины кабеля по сечениям. Работает как обычный сайт и как устанавливаемое PWA на компьютере и Android.

Внутри — чистые HTML, CSS и JavaScript без сборки и без сервера приложения. Все проекты хранятся локально в браузере (IndexedDB), экспортируются в JSON и не отправляются в интернет.

## Что умеет

- Рисовать стены и комнаты в масштабе, сетка и привязка к узлам.
- Добавлять дверные и оконные проёмы прямо на стены: положение вдоль стены, ширина, высота, подоконник, петли и сторона открывания.
- Ставить розетки, выключатели, светильники, бра, электрощит и распаячные коробки.
- Прокладывать кабельные трассы по плану, с изгибами и привязкой к устройствам.
- Считать длину каждой трассы и итоги по сечению, марке кабеля, цепи и этажу.
- Задавать запас на трассу отдельно или использовать общий запас проекта.
- Делать несколько этажей, переключаться между ними и удалять их с отменой.
- Сохранять проект автоматически, экспортировать и импортировать JSON.
- Формировать смету в CSV и печатный отчёт с сохранением в PDF через браузер.
- Работать офлайн после первого открытия и устанавливаться как PWA.

Важно: программа **не подбирает сечение кабеля и автоматические выключатели**. Сечения и цепи задаёт пользователь, приложение считает только метраж и формирует смету.

## Быстрый запуск на Windows

1. Установите Python 3 с [python.org](https://www.python.org/downloads/). При установке отметьте **Add Python to PATH**.
2. Откройте папку `electroplan`.
3. Дважды щёлкните **`Запустить ЭлектроПлан.bat`**.
4. Браузер откроется сам по адресу `http://127.0.0.1:8000/`.

Окно с сервером должно оставаться открытым, пока вы работаете с приложением. Остановка — `Ctrl+C` в этом окне.

Если Python уже установлен, можно запустить вручную из папки проекта:

```powershell
py -3 serve.py
```

или:

```powershell
python serve.py
```

Дополнительные параметры:

```powershell
py -3 serve.py --port 8080          # другой порт
py -3 serve.py --host 0.0.0.0       # доступ с других устройств в локальной сети
py -3 serve.py --no-browser         # не открывать браузер
```

Сервер нужен только для локального запуска. Для публикации достаточно выложить папку `electroplan` на любой статический хостинг с HTTPS.

## Установка как приложение

### Компьютер (Chrome или Edge)

1. Откройте `http://127.0.0.1:8000/`.
2. Нажмите значок установки в адресной строке или откройте меню браузера → **Установить приложение**.
3. Приложение появится в меню «Пуск» и будет открываться в отдельном окне.

`localhost` и `127.0.0.1` браузер считает безопасным адресом, поэтому установка и service worker работают и по HTTP.

### Android

Для установки PWA нужен **HTTPS** или **localhost**. Обычный адрес вида `http://192.168.1.10:8000` не считается безопасным: страница может открыться, но установка и офлайн-режим будут недоступны.

Варианты:

- **HTTPS-хостинг.** Выложите папку `electroplan` на GitHub Pages, Netlify, Cloudflare Pages или другой статический хостинг с HTTPS. Откройте адрес в Chrome на телефоне → меню → **Установить приложение**.
- **Локально через ADB.** Подключите телефон по USB с включённой отладкой и выполните:
  ```powershell
  adb reverse tcp:8000 tcp:8000
  ```
  Затем откройте на телефоне `http://localhost:8000/`. Это тоже безопасный адрес, установка будет доступна.

На iPhone приложение можно добавить через Safari: **Поделиться → На экран «Домой»**. Основная целевая платформа — Android/Chrome и ПК/Chrome или Edge.

## Как построить план

1. **Стены.** Выберите инструмент «Стена», кликните начало и конец. `Shift` удерживает линию ровно по оси. Толщина и высота задаются в свойствах проекта.
2. **Комнаты.** Обведите контур инструментом «Комната», завершите двойным кликом, `Enter` или кнопкой «Завершить». Площадь считается автоматически.
3. **Проёмы.** Выберите «Дверь» или «Окно» и кликните по стене. Проём перетаскивается вдоль стены, а его ширина, высота, подоконник, петли и сторона открывания задаются в инспекторе. Стена автоматически разрывается в месте проёма.
4. **Устройства.** Выберите тип в левой панели и кликните на плане. В инспекторе справа можно изменить название, координаты, высоту установки и группу/цепь.
5. **Трассы.** Выберите «Кабель», начните у устройства, добавьте точки изгиба и завершите у второго устройства. Двойной клик по готовой трассе добавляет точку.
6. **Сечение.** Выделите трассу и задайте сечение, число жил, цепь и при необходимости свой запас. Подписи сечения появляются при увеличении или у выбранной трассы.
7. **Смета.** Откройте вкладку «Смета»: итоги по сечениям, маркам, этажам и список трасс.
8. **Документы.** Нажмите «Отчёт PDF» для печати или «CSV» для таблицы. JSON-файл проекта сохраняется кнопкой «Файл проекта».

## Как считается длина

Для каждой трассы:

```
длина по плану
+ вертикальные спуски от высоты трассы до высоты установки начального и конечного устройства
+ 0,20 м на каждое подключение (настраивается в проекте)
+ запас (по умолчанию 10%, можно задать свой для трассы)
```

Пример: трасса 3,00 м по плану, два устройства с высотой установки 0,30 м, высота трассы 2,50 м:

```
3,00 + (2,50 − 0,30) × 2 + 0,20 × 2 = 7,60 м
7,60 + 10% = 8,36 м
```

Если для трассы поле запаса пустое, используется запас проекта. Значение `0` — это честный ноль процентов, а не «взять запас проекта».

Итоги группируются:

- по сечению — основной результат для закупки;
- по марке `жилы × сечение`;
- по цепи;
- по этажам.

## Отчёт, PDF и CSV

- **Печать / PDF.** Откройте «Отчёт» → «Печать / PDF». В диалоге печати выберите «Сохранить как PDF» (Chrome/Edge) или «Microsoft Print to PDF». Формат A4, книжная ориентация. Для цветных плашек включите «Фон и графика», если браузер их скрывает.
- **CSV.** Файл в UTF-8 с BOM и разделителем `;` — корректно открывается в Excel и LibreOffice. Десятичный разделитель — запятая.
- **JSON.** Полный проект со всеми этажами, настройками и трассами. Используйте его для резервной копии и переноса на другое устройство.

## Данные и резервные копии

Проекты хранятся в IndexedDB браузера, в профиле пользователя. Они не синхронизируются между устройствами автоматически.

- Регулярно сохраняйте **JSON-файл проекта**.
- Очистка данных сайта, режим инкогнито и удаление профиля браузера удаляют локальные проекты.
- При импорте проекта с тем же ID создаётся копия, существующий проект не перезаписывается.
- Для переноса на другое устройство: экспортируйте JSON на старом, откройте приложение на новом и загрузите файл через «Мои проекты» → «Загрузить JSON».

## Тесты

Откройте `http://127.0.0.1:8000/tests.html`. Проверяются геометрия, формула длины, запас проекта, сводка демо-проекта, клонирование, импорт, проёмы, подписи сечений и русские склонения. Сейчас проходят **23 из 23** тестов, демо-проект даёт **8 трасс и 75,17 м**.

## Ограничения

- Нет автоматического подбора сечения, автоматов, УЗО и проверки по нормам.
- Нет расчёта падения напряжения, токов КЗ и тепловых потерь.
- Нет облачной синхронизации и совместной работы.
- PDF формируется средствами браузера, а не отдельным генератором.
- При обзорном масштабе подписи трасс скрываются, чтобы не перекрывать план; выбранная трасса подписана всегда.
- Приложение не заменяет проект электрика и не гарантирует соответствие нормативным документам.

## Частые проблемы

**Браузер открылся, но пишет «Не удалось подключиться».**
Сервер ещё не запустился или окно с ним закрыто. Запустите `Запустить ЭлектроПлан.bat` заново и дождитесь строки с адресом.

**Порт 8000 занят.**
Запустите `py -3 serve.py --port 8080` и откройте `http://127.0.0.1:8080/`.

**На Android нет кнопки «Установить приложение».**
Вы открыли приложение по IP-адресу через HTTP. Нужен HTTPS-адрес или `http://localhost:8000` через `adb reverse`.

**После обновления видна старая версия.**
Обновите страницу. Service worker работает по стратегии «сначала сеть» и при доступной сети забирает свежие файлы. Если приложение установлено, закройте и откройте его снова.

**Пропали проекты.**
Проверьте, не очищались ли данные сайта и не открывалось ли приложение в другом профиле/инкогнито. Восстановить можно из ранее экспортированного JSON.
